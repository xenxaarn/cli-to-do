
# CLI To-Do

## A simple CLI To-Do program in C 

### Features :

```bash
1 = View a task
```
```bash
2 = Add a task
```
```bash
3 = Task Completed
```
```bash
4 = Delete a task
```
```bash
5 = Exit
```
###  How to run ?
```bash
git clone https://codeberg.org/xenxaarn/cli-to-do
```
```bash
cd cli-to-do
```
```bash
gcc -o main main.c
```
